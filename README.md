# RSMI MANAGEMENT SYSTEM
*The Report of Supplies and Materials Issued (RSMI) is a mandatory government form used to summarize all inventory items issued by stock number for a specific day. It is part of the Commission on Audit (COA) standardized forms for inventory management.*

>--Work in progress--

When I was working for a Philipppine Government Agency, I was assigned for the inventory section. I was tasked to process the RSMI forms. Even back then, I knew somehow it could be automated/systematic. However I didn't know how to make it possible. so had just do it manually... 

Now I know Python and to try the Flask Framework. I think that experience would be perfect problem that could be solved with this project. This project aims to make the process more systematic and organized. At the same time, a huge learning experiece with advanced Python, web development and practical uses to solve specific problems.
